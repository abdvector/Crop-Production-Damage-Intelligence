# Annual forecast comparison extension

Declared 22 October 2026 before fitting this extension. The annual study covers 50 historical districts in Bihar, Jharkhand, Odisha, Chhattisgarh and West Bengal. This extension saves comparable district-level forecast lines for all seven originally declared candidates, not a revised model search.

Use the original `district_years.csv`, original candidate list and `src/rice_regional.py` estimator settings. Fit learned comparators on years through 2004 only, exactly as for the original fixed annual assessment estimator. Predict the identical 300 district-years in 2012–2017. No annual refit, new features, outcome-based exclusion, hyperparameter tuning or selection on these outcomes. Reuse the selected History Ridge artifact rather than replacing or refitting it. Retain the source study's historical district geometry and monthly-weather assumptions.

Candidates: recent mean; last available yield; historical trend; History Ridge alpha 100; Weather Ridge alpha 100; Weather Random Forest (300 trees, minimum leaf 8, max_features 0.8, seed 42); Weather histogram gradient boosting (200 iterations, learning rate .05, seven leaves, minimum leaf 15, L2 10, no early stopping, seed 42). Fit training-only median imputation, scaling and geography encoding using the existing pipeline. Preserve fitting row order, all source features, historical reference calculation and nonnegative clipping. Numerical work uses two threads.

Only the selected Ridge and three baselines had original assessment scores. Require their reproduced predictions/scores to agree with those originals within numerical tolerance (predictions 1e-7 kg/ha absolute; score differences 1e-7). Weather Ridge, forest and boosting are newly materialized **retrospective comparators** on already inspected outcomes, not previously saved results or independent validation. No new superiority or deployment claim follows. Do not replace the original selection even if a comparator has a smaller assessment error.

Do not copy Ridge intervals or risk probabilities to another model. The primary Ridge retains its saved intervals; other methods receive no interval unless separately calibrated under a new declared plan. The UI must handle missing intervals honestly.

Before fitting, verify the original dataset and protocol hashes against selection.json and the model artifact against summary.json. Save source, code, artifact, environment and protocol hashes in a run declaration. On completion, save seven predictions per district-year (2,100 total), aggregate scores and numerical verification under `data/processed/rice/regional_comparison/`. Existing source data, model, selection, calibration and assessment files must remain byte-for-byte unchanged. Completed reruns verify receipts without fitting. Run through the sole launcher: `python app.py --compare-annual-models`.

Expose all seven methods for every annual-study district, with state/district/full-study evaluation filters. Preserve the original default, History Ridge. This is an interface coverage improvement, not a claim of reliable forecasting, causal damage measurement or protein/aluminium integration.
