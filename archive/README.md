# Earlier studies

`previous_studies.zip` preserves the previous application, 11 research modules, original study protocols/results documents, dependency list, Streamlit configuration, CSS and annual model. Every archived file is listed with its SHA256 in `ARCHIVE_MANIFEST.json`. No original research source was edited to make old verification receipts pass.

The datasets and saved study outputs still live in the project's `data/` directory. Papers, figures and local mentor materials remain in their existing folders. This archive is evidence of previous work, not the active prediction application.

To inspect or reproduce an earlier study, extract the ZIP into a separate empty working directory, copy the project's complete `data/` directory into that directory, and use the original dependency versions and archived launcher. Copy `docs/figures/` too if viewing the original dashboard screenshots. Do not extract over the active project. Any original verification command must pass its saved receipts before its results are relied on. Ignored raw caches are local and are not all available from a Git clone.

The new numerical-input experiment has its own code, method and artifacts; it does not replace or improve the previous accuracy claims by declaration.
